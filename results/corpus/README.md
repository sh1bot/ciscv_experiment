# Corpus scores, six binaries

Generated by `util/corpus_scores.py`. Sizes are bytes against a
4-byte-per-instruction baseline; `vs RVC` under 100% means packets are smaller
than the compression the binary actually shipped. `P/(C/2)` is progress toward
break-even: packets cost `4*(N-P)` and RVC costs `4N-2C`, so packets win exactly
when pairs exceed half the compressed-instruction count.

RVC figures are REAL, taken from the `-noalias` disassembly, not the
`rvc_eligible` estimator (which is a ceiling — see CLAUDE.md).
